About

I've been interested in web and software development since long before I formally studied computer science. I enjoy building things that are not only functional, but also thoughtfully designed, and I'm always curious about how things work beneath the surface.

I've built across the development stack from React to backend development, MERN, SQL and NoSQL databases, and deploying applications manually with PM2 and Nginx. Overview

A full-stack student management system built for a teacher to manage students, courses, attendance, assignments, materials, announcements, grades, and student progress. The system supports distinct teacher and teaching-assistant roles, while students can access their courses, download materials, submit assignments, track their progress, and download grade reports.

What I learned

Building and maintaining a real-world system taught me how to design role-based access, manage files and data, handle authentication, build production-ready features, and deploy and maintain a full-stack application.

Overview

A retrieval-augmented question-answering system built to answer questions from the East West University bulletin. The system combines semantic retrieval with BM25 lexical search to retrieve relevant information before passing the context to a locally running language model.

What I learned

Building the system gave me hands-on experience with document retrieval, embeddings, hybrid search, context construction, and integrating local LLMs into an end-to-end RAG pipeline.
