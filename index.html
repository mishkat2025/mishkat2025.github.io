EWU Bulletin — RAG Assistant

2026

A retrieval-augmented question-answering system built to answer questions from the East West University bulletin. The system combines semantic retrieval with BM25 lexical search to retrieve relevant information before passing the context to a locally running language model.

What I learned: Building the system gave me hands-on experience with document retrieval, embeddings, hybrid search, context construction, and integrating local LLMs into an end-to-end RAG pipeline.
